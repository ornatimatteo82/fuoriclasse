🚀 Prospetto Deploy & Login Utenti

1. HAI UN HOSTING WORDPRESS? (ZERO COSTI EXTRA)

Come caricarlo senza toccare WordPress

Fuoriclasse è una Progressive Web App statica pura (HTML5 + CSS3 + JS + JSON). Non serve né Node.js né PHP:

  • ✅ Opzione A — Sottocartella sul tuo Hosting WP: tramite File Manager (cPanel / Plesk / SiteGround) o FTP, crea la cartella public_html/fuoriclasse/ e trascina dentro i file del gioco. WordPress resta intatto e il gioco risponde su tuosito.it/fuoriclasse/.
  • ✅ Opzione B — Cloudflare Pages / Netlify (Gratis): trascina la cartella su app.netlify.com/drop e opzionalmente collega un sottodominio gioco.tuosito.it via record CNAME.
2. COME AGGIUNGERE LA LOGIN E CLASSIFICA REALE?

Opzioni per Autenticazione e Salvataggio Cloud

Al momento i progressi (XP, Streak, Cuori, Lezioni sbloccate) sono salvati in localStorage. Se vuoi che gli utenti facciano login da telefono e PC mantenendo l'account:

  • 🏆 Soluzione Consigliata: Supabase (Free Tier 50.000 utenti/mese gratis)
    Basta includere lo script CDN di Supabase e hai pronti:
    • Login con Google / Apple / Email Magic Link (senza password da ricordare)
    • Tabella PostgreSQL profiles per sincronizzare XP, Streak e la Classifica Settimanale in tempo reale.
  • 🔥 Alternativa: Firebase Authentication + Firestore (Google)
    Gratuito con piano Spark, ottimo per login rapida con Google o account ospite convertibile.
